A small pathology unknowns prototype using the 10 most recent cases sampled from the Johns Hopkins Surgical Pathology Unknown Conference. Images are displayed from their original JHU media URLs and are not stored in this repository.

The autocomplete pool is built from all answer choices in these 10 source cases. The official answer key for these newest JavaScript quizzes is not exposed in the public static text used for this demo, so this prototype does not fabricate correctness.
Educational prototype. Case wording, attribution, and linked images originate from the Johns Hopkins Surgical Pathology Unknown Conference. Each case links back to its original source page.
